# Portal title projection

Files representing `Portal:*` titles used by V2 navigation.

Important: the archived 2026-08-18 MediaWiki namespace configuration does **not** list a dedicated Portal namespace. Until live `Special:NamespaceInfo` is reconciled with the repository, treat this directory as a title/filesystem projection rather than proof that namespace `Portal` is configured.

Portals are navigation views, not ontology and not substitutes for semantic relationships, contents, outlines, lists, or categories.
