# Template namespace

Deployable V2 `Template:*` source.

This directory is currently **not a complete inventory of BITwiki's templates**. The V1 archive contains additional live/historical templates (including the heavily used `Template:Infobox`) that have not yet been reconciled and promoted into V2.

Before promotion, recover the current live revision and classify each template as canonical, compatibility, deprecated, or infrastructure. Templates should provide reusable declarative composition/semantic surfaces; nontrivial reusable logic belongs in Scribunto/Lua where appropriate.
