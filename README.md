# BITwiki content

Public working source for the BITwiki V2 content architecture.

- **Live BITwiki (`bitwiki.org`) is the source of truth for existing public content.**
- **This repository is the V2 workspace.** V2 may reorganize structure while preserving the substance, citations, and provenance of inherited content.
- **Public information only.** Protected, private, credentialed, or non-public operational material does not belong here.
- Directories mirror MediaWiki namespaces; source pages use `.mediawiki`.

V2 is being rebuilt around native MediaWiki semantics, modular **Book Matter**, Semantic MediaWiki relationships, explicit epistemics, and reusable/transcludable knowledge.

Start with `BITwiki/V2.mediawiki`.
