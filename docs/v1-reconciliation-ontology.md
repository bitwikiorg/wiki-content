## Durable V1 signal confirmed in current canon

The current ontology layer preserves the strongest V1 design principles:

- types are useful lenses that can evolve;
- entity identity, Domain, Category/Portal navigation and epistemic standing are separate dimensions;
- polyhierarchical and faceted navigation is legitimate;
- relationships must have explicit meaning and direction;
- strong graph claims require support and do not become true through storage;
- inverse display, persisted inverse assertions and logical inference are distinct;
- schema/property expansion must come from recurring use and tests;
- external mappings must preserve semantic differences, direction, context, provenance and information loss;
- ontology is a purpose-built model, not a metaphysical claim that the schema exhausts reality;
- classification boundaries and models can remain provisional and contested.

## Explicitly deprecated/superseded V1 mechanisms

The following are not silently discarded:

- Topic as one overloaded universal primitive;
- automatic multiple entity types as the default identity model;
- fixed root taxonomy / mandatory primary category;
- numeric category confidence;
- automatic inverse assertions;
- blanket domain/range/transitivity assumptions without implementation;
- a universal catalog of 18 historical relationships as current schema;
- universal EAV as BITwiki's required representation;
- processual attractor ontology as executable current ontology;
- EPV as foundational ontology/property naming law;
- unverified cross-system equivalence tables;
- claimed RDF/SPARQL/import/export behavior without deployment evidence;
- historical visual color semantics tied to old entity types.

## New incorporation from this audit

V1's useful visualization/accessibility principles were not adequately represented. They are now integrated into `BITwiki:Page format` rather than restoring the obsolete standalone Visual Diagram Specification.

## Result

All 16 V1 ontology/semantics/relationships architecture sources are content-reconciled for issue #152.

This closes only this architecture family. It does not close issue #152 or authorize archive retirement.
