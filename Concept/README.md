# Concept namespace

Source for Semantic MediaWiki `Concept:*` pages.

A Concept is a **named semantic query / dynamic set**, not another category tree and not an entity type. Use one when the same computed set has real reuse value in queries, navigation, maintenance, or exploration.

The captured live V1 Concept namespace was configured but empty. V2 therefore introduces Concepts progressively rather than inventing a catalog to populate the namespace.

`Computer science.mediawiki` is the first proof: it represents pages explicitly annotated with `Domain::Computer science`.

See `BITwiki/MediaWiki substrate.mediawiki` and Semantic MediaWiki's Concepts documentation.
